Slide 05 • System Architecture

End-to-End System Architecture

Hybrid Pipeline: Deterministic Guardrails + ChromaDB RAG + LangChain LLM

  • Ingestion & Parsing: Pydantic models validate raw transcripts, emails, calendars, and audio transcripts from data/source_data.json.
  • ChromaDB Vector Store: Sentence-Transformers (all-MiniLM-L6-v2) generate dense vector embeddings for semantic document search.
  • Deterministic Grounding Engine: Enforces zero-invention guardrails on critical compliance and unowned legal items.
  • Serving & Observability: FastAPI REST API + Streamlit Dashboard + SQLite (agent_audit.db) recording complete query history.

Handling Ambiguity & Anti-Hallucination

  • The Potential Trap: Facilities issued two company-wide alerts for signature due Friday 25 Sep. Divya suggested in sync that Facilities typically owns it.
